# دليل تشغيل الواجهة الخلفية بلغة PHP لمنصة سكينة للدعم النفسي 🕊️
### Sakina Platform - PHP Backend & XAMPP Deployment Guide

لقد قمنا بتصميم واجهة خلفية برمجية متكاملة ومطابقة 100% باستخدام لغة **PHP** الخام (Pure Vanilla PHP) تلبيةً لمتطلبات ميثاق النظام ومناقشة التخرج الأكاديمية (Section 8.1 - Implementation Plan).

---

## 📂 هيكلية ملفات PHP المدمجة:
1. `api.php`: يمثل الموزع الذكي لجميع نقاط الاتصال (RESTful Router)؛ يقوم بمعالجة وحفظ البيانات وتشفيرها فورياً داخل خزانة `db.json` باستخدام قفل المعاملات الحصري (`LOCK_EX`) لمنع تداخل الجلسات.
2. `db.json`: قاعدة البيانات والملفات المشتركة المشفرة (تلقائية الإنشاء في المجلد الأب).

---

## 🛠️ كيفية التشغيل والتهيئة المحلية عبر بيئة XAMPP:

1. **نسخ السورس كود**:
   - قم بضغط مجلد المشروع بأكمله من محرر الأكواد بصيغة ZIP ثم قم بفك الضغط عنه داخل مسار مشاريع خادم الويب المحلي في مجلد XAMPP:
     `C:\xampp\htdocs\sakina\`

2. **تشغيل الخوادم**:
   - افتح لوحة تحكم XAMPP Control Panel وقم بتشغيل خادم **Apache Web Server**.

3. **مسار نقاط الـ API**:
   - ستعمل لوحة التحكم وجميع واجهات הـ API الخلفية لغة PHP مباشرة تحت المسار المحلي:
     `http://localhost/sakina/php-backend/api.php`
   - يتم تمرير المسارات الفرعية تلقائياً عبر المعامل `route`. مثال:
     * تتبع الاستشارة: `http://localhost/sakina/php-backend/api.php?route=/api/consultations/SK-1234`
     * سحب البيانات الإحصائية: `http://localhost/sakina/php-backend/api.php?route=/api/doctor/statistics`

4. **ربط الواجهة الأمامية (Vite Production Build)**:
   - بمجرد قيامك ببناء الواجهة الأمامية عبر الأمر `npm run build` في جهازك، سيتم تصدير ملفات الـ React الساكنة بالكامل داخل مجلد `dist`.
   - قم بالتحويل الذكي لعناوين الاتصال ومسار الواجهة الخلفية في ملفات الـ Components لتشير إلى رابط الـ PHP المحلي بدلاً من خادم الـ Node.js، وبهذا تحصل على تطبيق متكامل يعمل بنسبة 100% بلغة PHP على جهازك الشخصي أمام لجنة التقييم الموقرة.

---

## 🔐 التقنيات الأمنية والاحترازية المطبقة في كود PHP:
* **تشفير تماثلي AES-256-CBC**: تطابق تام في التشفير الثنائي للرسائل والردود الطبية لمنع تسرب البيانات الإكلينيكية حتى في حالة الهجمات العنيفة.
* **تشفير الملح التفاعلي المعتمد على الـ PIN**: تملك الاستشارة والرد مفتاح تشفير ديناميكي مرتبط بهاش الـ PIN الفرعي الخاص بالنزيل ليكون هو المتحكم الوحيد بالطمس والتظليل العاطفي.
* **مكافحة ثغرات الحقن**: تطهير تام ومطابقة نصية مدعومة بـ `normalizeArabicText` لمطابقة الأسئلة الأمنية المقترحة واسترداد الـ PIN المنسي بمرونة تامة ونعومة عقلية فائقة.
